# OnePointer 0.1.1

聚焦动画现在更清晰、更直接。

- 大聚光圈快速收拢到鼠标位置
- 轻微回弹后稳定，并在 0.85 秒内淡出
- 开启“减少动态效果”时，保持固定圆圈并仅淡入淡出

The focus animation is now clearer and more direct.

- A large spotlight rapidly contracts toward the pointer
- It lightly rebounds, settles, and fades within 0.85 seconds
- Reduce Motion keeps the circle fixed and uses opacity only
