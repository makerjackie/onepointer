# OnePointer 0.4.0

## 简体中文

- 新增菜单栏模式：隐藏 Dock 和 ⌘⇥ 图标，在屏幕顶部菜单栏随时找回 OnePointer。
- 设置侧栏新增“在后台运行”和“退出 OnePointer”，清楚区分收起窗口和完全退出。
- 菜单栏可立即聚焦指针、开关持续高亮、打开设置、检查更新和退出。
- 修复关闭或最小化设置后重新打开 App 时，窗口无法正常恢复的问题。
- 开机启动安静地在后台运行，不再弹出设置窗口。
- 修复快速聚焦快捷键开关慢一拍的问题，避免权限监听失败时反复重试。
- 演示帧率切换立即生效。

菜单栏模式默认关闭；点击“在后台运行”即可启用。关闭窗口会继续运行；点击
“退出 OnePointer”或在设置窗口按 ⌘Q 可完全退出。

感谢 @OpenAndrus 在 PR #1 中贡献菜单栏模式和快捷键修复。

## English

- Optional menu-bar mode hides OnePointer from the Dock and ⌘⇥ while keeping it
  available at the top of the screen.
- Clear “Run in Background” and “Quit OnePointer” sidebar actions.
- Focus the pointer, toggle persistent highlighting, open Settings, check for
  updates, and quit directly from the menu bar.
- Reopening the app restores closed or minimized Settings reliably.
- Launch at login runs quietly without opening Settings.
- Quick-focus switches take effect immediately; failed input listeners no longer
  trigger recursive authorization refreshes.
- Presentation frame-rate changes apply immediately.

Menu-bar mode is off by default. Choose “Run in Background” to enable it. Closing
Settings keeps the app running; choose Quit or press ⌘Q in Settings to stop it.

Thanks to @OpenAndrus for the menu-bar mode and shortcut fixes in PR #1.
