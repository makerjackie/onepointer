# OnePointer 0.2.0

快速聚焦快捷手势现在可以自由选择，也可以关闭。

- 默认快捷手势改为双击左侧 Option
- 可选择左右侧的 Option、Control、Command 或 Shift
- 可完全关闭快速聚焦快捷手势
- 修饰键与其他按键组合使用时不会误触聚焦

---

The quick-focus gesture is now configurable and optional.

- The default gesture is now double-tap left Option
- Choose either side of Option, Control, Command, or Shift
- Disable the quick-focus gesture completely
- Modifier-key combinations do not accidentally trigger quick focus
