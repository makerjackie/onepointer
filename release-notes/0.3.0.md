# OnePointer 0.3.0

设置界面经过重新设计，让快速聚焦与持续高亮都更容易找到和使用。

- 只保留“快速聚焦”和“持续高亮”两个清晰入口
- 持续高亮改为醒目的全宽主按钮，可一键开启或关闭
- 所有设置直接展示，不再折叠“高级设置”
- 开机启动、检查更新、帧率和重置整合到快速聚焦页
- 全新 App 图标更明确地表达鼠标指针与聚焦功能
- 新增 OneApps.Studio 更多实用 App 入口

---

The settings window has been redesigned to make both quick focus and persistent
highlighting easier to find and use.

- Two clear destinations: Quick Focus and Persistent Highlight
- A prominent full-width control enables or disables persistent highlighting
- All settings stay visible without a collapsed advanced section
- Launch at login, updates, frame rate, and reset now live on the Quick Focus page
- A refreshed app icon clearly communicates pointer focus
- A new link helps users discover more apps from OneApps.Studio
