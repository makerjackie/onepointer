# OnePointer 0.1.0

首个公开版本。

- 双击同一侧 Control，短暂灰屏并聚焦鼠标位置
- 保留圆形、聚光灯、圆环、十字准星和脉冲演示模式
- 保留涟漪、颜色闪光和收缩回弹点击效果
- 支持多显示器、全屏空间和开机启动
- 简体中文与英文界面
- 使用 Sparkle 提供安全的自动更新

---

First public release.

- Double-tap the same Control key to briefly dim every display and focus the pointer
- Circle, spotlight, ring, crosshair, and pulse presentation modes
- Ripple, color-flash, and shrink-and-bounce click effects
- Multiple displays, full-screen Spaces, and launch at login
- English and Simplified Chinese interface
- Secure automatic updates powered by Sparkle
