# OnePointer 0.3.1

首次授权流程现在更清楚，也不再需要手动寻找 App。

- 首次启动时先说明为什么双击快捷手势需要“输入监控”
- 点击“继续并授权”后，由 macOS 将 OnePointer 加入权限列表
- 用户只需打开 OnePointer 右侧开关，不再需要点击 `+` 手动添加
- 可以选择“暂不授权”，不影响立即聚焦和持续高亮
- 权限区域会根据当前状态只显示一个清晰的下一步操作

---

The first-run permission flow is now clearer and no longer asks people to find
the app manually.

- Explains why the double-tap gesture needs Input Monitoring before requesting it
- Uses the macOS HID authorization flow to add OnePointer to the permission list
- Users only need to turn on the OnePointer switch instead of adding it with `+`
- “Not Now” keeps Focus Now and persistent highlighting available
- The permission area shows one clear next action for the current state
